This repository hosts the public **Privacy Policy** page for **Minto**, a WhatsApp ordering service run by **Nirmala Devi and Sons**.

Minto lets buyers pick products from retail shops near them and place an order inside WhatsApp. The order goes to the shopkeeper, and it is delivered to the buyer. Buyers and shopkeepers use only WhatsApp; there is no app to install.

## Live page

The policy is published with GitHub Pages:

**https://&lt;your-github-username&gt;.github.io/minto-privacy/**

This URL is used as the Privacy Policy URL for the Minto app on the Meta (WhatsApp Business Platform) developer dashboard, so it must stay public and reachable.

## Updating the policy

1. Edit `index.html` (click the file, then the pencil icon).
2. Change the **Last updated** date near the top of the page.
3. Commit to `main`. GitHub Pages republishes in a minute or two.

If a change affects what data Minto collects or who it is shared with, also update the chatbot so it does what the policy says.
